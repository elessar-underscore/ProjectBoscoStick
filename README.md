## Hub

The hub will have much more of the context specific behavior with a lot of different things happening most likely.
For now though this is the behaviors that have been decided on

### Joining a Team
Joining a team currently works by a player entering a specified area.
Then the players tags are stripped and the new team tag is placed on them.
Finally it is saved into memory to be handled by other scripts.
